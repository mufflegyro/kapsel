Small maintenance release of Yummle, the opinionated fork of Kapsel.

## Changed

- **The Updates check now leads the settings readiness list.** The Updates entry — a pending release offer, or a warning like "The latest release check did not succeed" — is the one that most often needs a decision, so it appears at the top of the readiness checks instead of the bottom.

No other behavior changed; this release exists mainly so running v1.0.0 archives can exercise the new self-update flow end to end: Settings → Updates → Check now → approve → the archive swaps itself to this release, verifying the SHA-256 checksum and taking a database backup first.
