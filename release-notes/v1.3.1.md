Yummle v1.3.1 is a major refactor of how search results are ranked and experienced: matching, counting, ranking, and browsing the archive's search page are all rebuilt around what a query actually means — and every result is now reachable, not just the first page.

## Fixed

- **Multiword queries match all the words.** "island cabin" previously required the exact phrase; each word is now matched independently and combined (AND), so "video tour" finds "Tour of My New Video Studio Setup" even when the words are far apart. Search input still cannot inject query operators.
- **Channel names are searchable together with topics.** Videos are indexed with their channel's name, so "adam stew island" finds Adam Stew's island uploads — previously such channel-plus-topic queries could match nothing at all. Channel renames propagate to existing videos, and existing archives are backfilled automatically.
- **The results count tells the truth.** The subtitle counts unique videos, channels, and playlists across the entire match set — no longer capped at the 50 rows the page happened to show.

## Changed

- **Ranking balances relevance, field, and freshness.** Titles outrank descriptions, which outrank transcripts and comments; each video's contribution gently decays with age (three-year half-life). Frequent terms no longer return pages dominated by a decade of short old titles — on a live archive, "island" went from 30 of the first 50 results published 2021 or earlier (5 from 2026) to an entirely recent page, while strong older matches remain reachable on later pages.
- **Channels and playlists rank on their own merits.** They carry no publish date, so they are ranked by pure relevance — names above descriptions — in a pool independent of video volume. A channel matching only by description surfaces even when thousands of videos match the same term, and the "Channels & playlists" block keeps its relevance order on every page.
- **One card per channel in the block.** A channel matching through both its name and its description takes a single slot.
- **Load-more is compact.** The "Channels & playlists" block renders as a responsive grid so a full block of cards no longer pushes the episode grid far down the page.

## Added

- **Lazy loading on search results.** Scrolling (or the "Load more" button) appends the next page of episodes until every distinct match is reachable — the count label and what you can actually browse now agree. Pages never repeat a video: the server deduplicates each video's multiple matches (title, description, subtitles, comments) into its best single match before paging, and a polite status line tracks progress ("Showing X of Y results.").
- **Offset paging on the search API.** `GET /api/search` accepts `offset` and echoes it back, enabling the client-side paging above.

Upgrade note: the archive is re-indexed automatically on first start (migration 017 backfills per-video channel documents); no configuration is required.
