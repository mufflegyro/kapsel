Yummle v1.2.0 is about spending less time on videos you have already finished — and getting back to what's next faster.

## Added

- **A "Hide watched" filter for the sort toolbar.** The "Sort by" dropdown on the home and channel pages now offers a "Hide watched" checkbox. Enabled, it removes finished videos — marked watched directly or via watched playback progress — from every sort mode: Newest, Oldest, Recently Downloaded, Length, Popularity. The filtering happens server-side, so page sizes and pagination totals stay accurate instead of leaving holes the way client-side hiding would. Your choice round-trips through the URL (`?hide_watched=1`) so a filtered view survives a reload and can be bookmarked, and on the home page it sticks between visits just like the sort selection does. The For You feed already excluded finished videos; the checkbox extends that behavior to the rest of the library. Watching a video while the filter is on makes it quietly disappear from the list when you return.

## Changed

- **The Yummle logo always opens For You.** The brand link in the header now navigates to the For You feed (`?sort=watching`) no matter which sort the home page had saved, so the logo is a reliable one-click jump to unfinished videos. The sidebar Home link still opens the plain home page, which keeps its own sticky sort — the explicit `?sort=watching` on the logo overrides the saved choice without overwriting it.

No schema changes; upgrading is a drop-in binary swap.
