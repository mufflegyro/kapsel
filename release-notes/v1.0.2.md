Maintenance release of Yummle, the opinionated fork of Kapsel, with two interface fixes reported while testing the v1.0.1 self-update flow.

## Fixed

- **Offer-flow buttons are visible again.** In Settings → Updates, the Dismiss button and the confirm dialog's Cancel button carried no styling, so they rendered as a light button face with near-white text on the dark theme — effectively invisible. Both now use the app's secondary button style.
- **The home sort dropdown no longer misses a refresh.** When the picked sort resolved to the same URL as the current one — picking the default sort while a different sticky sort was active — the video grid kept showing the old items until a manual page reload, and the dropdown snapped back. The list now refreshes immediately, with an e2e regression test covering the case.

No backend behavior changed.
