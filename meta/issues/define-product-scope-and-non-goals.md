# Define product scope and non-goals

## Summary

Define the initial product boundaries so Kapsel stays intentionally small and does not recreate the full complexity of TubeArchivist by accident.

## Requirements

- Document the target user and archive scale.
- Decide which TubeArchivist features are required for the first usable version.
- Decide which features are explicitly out of scope for the first usable version.
- Capture expected limits for videos, comments, subtitles, channels, and playlists.

## Acceptance Criteria

- `README.md` includes a clear scope section and non-goals section.
- The issue list is updated if scope decisions create new implementation work.
- Any intentionally dropped TubeArchivist feature is documented with a reason.

## Notes

- Assume personal single-node use unless this issue decides otherwise.
